# Koleksi video impor Downloads/se

Semua 11 sumber tetap di folder asal, hanya diganti nama. Salinan proyek diverifikasi SHA-256 sama dengan sumber. Deskripsi berdasarkan gambar yang terlihat, dapat dikoreksi lewat Koleksi video. Identitas orang dan merek yang belum jelas tidak ditebak.

## Fungsi kolom

| Kolom | Kegunaan |
|---|---|
| title | Nama yang tampil di koleksi. |
| hashtags | Beberapa label untuk pencarian dan filter Mix opsional. |
| explain | Penjelasan isi visual dan konteks pemakaiannya untuk AI. |
| scenes | Rentang adegan dan deskripsi lebih spesifik; waktu internal memakai frame 30 fps. |
| url_path | Lokasi salinan sumber di storage proyek; dikelola aplikasi. |
| duration, width, height | Durasi dan ukuran sumber, dibaca otomatis. |
| id | Identitas tetap aset, dipakai timeline. |
| status, error | Kesiapan proxy atau alasan gagal. |
| archived | Menyembunyikan dari pilihan baru tanpa merusak proyek lama. |
| revision | Mencegah penyimpanan menimpa revisi lain. |
| created_at | Waktu ditambahkan. |

Kolom type telah diganti hashtags. Filter dengan beberapa hashtag memakai kecocokan semua hashtag terpilih (AND). Tanpa pilihan berarti semua footage siap pakai. Jika tidak ada kecocokan, tidak mengambil footage di luar filter. Audio sisipan tetap mute.
